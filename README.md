# Data Analyses At A Global Scale 

Understanding data and trends on a global scale is a key part of marine science, and Google Earth Engine (GEE) provides an easy platform to perform these global analyses. This module took us through the basics of JavaScript code and some of GEE's capabilities. We used this knowledge to analyse changes in global nightlight and population changes to identify key areas for mangrove decline due to urbanisation, plan a field research trip, and create an interactive app to display key deep sea ocean ecosystems.
